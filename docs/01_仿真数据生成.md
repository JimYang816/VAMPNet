> 项目名称：**VAMPNet**。
> 文档版本：1.0。本文是待实施的执行规范，不代表数据已经生成或检验已经通过。
> 目标：从接收训练序列实际估计 CSI，使估计误差自然产生；冻结可直接输入四种均衡器的数据。
> 配套文档：[baseline](02_Baseline算法实现.md)、[VAMP 深度展开](03_VAMP_DeepUnfolding实现.md)、[评估与增量缓存](04_统一评估与增量重测.md)。

## 0. 必须先冻结的项目约定

1. 正式数据禁止通过 `H_hat = H_true + random_error` 产生不完美 CSI，也禁止将估计误差缩放到预设 NMSE。`H_hat` 必须是同一接收估计器对已知训练序列的输出。
2. 发射波形、路径轨迹和噪声只生成一次；均衡器、训练器、评估器均不得重新抽取正式测试样本。正式测试读取已封存的数据。
3. 数据生成器不知道正在比较哪种均衡器。不能按某个算法的 BER 或收敛情况筛选、重新生成或删除样本。
4. 训练、验证、测试以独立信道轨迹为划分单位；同一轨迹的不同块、不同 SNR 和不同噪声重复必须属于同一个集合。
5. `vamp_du/v1` 采用原数学设计中的**固定 CSI 核心版**；结构化细化完整保留为显式的 `v1_refine` 变体。两者读取完全相同的接收数据。此版本选择在文档 03 中进一步固定。
6. 第一轮正式基准为未编码 QPSK：报告 `BER_pre_FEC`，不把它命名为“译码后 BER”。启用纠错编码时另建数据版本，并为四种算法使用同一编码器、交织器和译码器。
7. 主数据定义在**公共粗多普勒补偿之后的残余信道域**，研究不完美 CSI 与残余宽带 ICI 下的均衡；帧起点由协议固定。这里不模拟粗捕获失败，也不声称验证了原始带通信号的完整同步性能。CSI 本身仍来自实际接收训练序列，而非真值。
8. 所有统计结果均绑定数据内容哈希；相同种子不是数据相同的充分证据。跨软件、硬件的逐位一致性不作无条件保证，正式复用以封存字节与锁定环境为准。[D3][D4]

## 3. 符号、索引与发送波形

### 3.1 星座及类别顺序

固定

$$
 a(b_1,b_2)=\frac{(1-2b_1)+j(1-2b_2)}{\sqrt2},\qquad c=2b_1+b_2.
$$

类别 $c=0,1,2,3$ 对应比特 `00,01,10,11`。所有网络概率的最后一维必须采用此顺序。

FFT 自然顺序下，

$$
 f_k=\begin{cases}kF_s/N,&0\le k<N/2,\\(k-N)F_s/N,&N/2\le k<N.\end{cases}
$$

活动位置先按有符号频率从低到高排列，再每四个活动位置选一个导频。保存 `data_idx[D]`、`pilot_idx[P]`、`null_idx` 和 `data_group[D]`，禁止各算法自行推断或排序。数据输出按 `data_idx` 顺序排列。

记 $\mathbf E_d,\mathbf E_p$ 为选择矩阵，则

$$
\mathbf s_b=\mathbf E_d\mathbf x_b+\mathbf E_p\mathbf p_b.
$$

导频和训练序列通过独立种子生成并作为公开协议资产保存；接收端直接读取这些已知序列。两个训练块在全部活动子载波发送已知 QPSK；数据块保持同一导频布局。

### 3.2 FFT 与 CP

$$
[\mathbf F]_{kn}=N^{-1/2}e^{-j2\pi kn/N},\quad
\mathbf u_b=\mathbf F^H\mathbf s_b.
$$

代码采用 `fft(..., norm="ortho")` 与 `ifft(..., norm="ortho")`。CP 是有效样本末尾 `cp_samples` 点的复制。

为了独立检查插值误差，参考生成器使用连续 OFDM 表达式：

$$
 x_b(u)=\frac1{\sqrt N}\sum_{k\in\mathcal K}s_{b,k}e^{j2\pi f_k u},
 \quad -T_{CP}\le u<T_u.
$$

以每块真实发送起点拼接成 $x(t)$。传播模块在任意时刻 $t'$ 应查询它属于哪个块或哪个保护区，不能对任意越界时刻都循环回当前块。可优化矩阵求值，但不能改变上述连续数据包语义。

## 4. 真实时变路径与完整 ICI

### 4.1 路径生成

每条轨迹先生成路径数 $P_h\sim\operatorname{UniformInteger}(4,10)$。令第一条超额时延为 0，其余从 $U(0,20\text{ ms})$ 独立均匀抽取并排序。设

$$
\tau_{p,0}=4\text{ ms}+\tau_{p,ex},\quad
P_p=\frac{e^{-\tau_{p,ex}/\tau_d}}{\sum_r e^{-\tau_{r,ex}/\tau_d}},\quad
g_p=\sqrt{P_p}e^{j\theta_p},\quad\theta_p\sim U(-\pi,\pi).
$$

每条轨迹的 $\tau_d\sim U(0.004,0.008)$ 秒。给定 regime 的均值上界 $a_{max}$ 和正弦幅度上界 $A_{max}$，每条路径独立抽取

$$\bar a_p\sim U(-a_{max},a_{max}),\quad A_p\sim U(0,A_{max}),\quad
f_{m,p}\sim U(0.15,0.8)\ \mathrm{Hz},\quad\phi_p\sim U(-\pi,\pi).$$

发送数据的每一比特独立服从 Bernoulli(1/2)，协议训练/导频同样由其固定独立随机流生成。物理时间 $t=0$ 定义为整个包含 quiet/guard 区间的数据包起点，所有块时刻相对该起点记录；不会在某个 OFDM 块处重置时间。取

$$
a_p(t)=\bar a_p+A_p\sin(2\pi f_{m,p}t+\phi_p),
$$

$$
\tau_p(t)=\tau_{p,0}-\bar a_pt+
\frac{A_p}{2\pi f_{m,p}}\left[\cos(2\pi f_{m,p}t+\phi_p)-\cos\phi_p\right].
$$

必须满足 $-\tau_p'(t)=a_p(t)$。同一轨迹中的所有块共用这条连续函数，不能逐块重置相位。

### 4.2 传播公式

$$
 r(t)=\sum_{p=1}^{P_h}g_p\,x(t-\tau_p(t))e^{-j2\pi f_c\tau_p(t)}+n(t).
$$

时变时延与载频相位在这里由同一 $\tau_p(t)$ 决定。不能另外叠加一份代表同一运动的多普勒相位。对基带频率 $f_m$，运动引起的瞬时频移为

$$
\Delta f_{p,m}(t)=(f_c+f_m)a_p(t).
$$

频率相关的时间尺度效应是宽带模型的关键；不能用统一频偏替代而仍称为同一模型。[D1][D2]

### 4.3 接收窗与单块条件

主版本采用固定接收窗，令数据块有效起点为 $t_b$，接收样本时刻为 $t_{b,n}=t_b+n/F_s$。每条路径、每个样本都检查

$$
 -T_{CP}\le t_{b,n}-\tau_p(t_{b,n})-t_b<T_u.
$$

若不满足，则当前块可能包含块间干扰。生成器必须记录失败原因，不能悄悄用循环卷积“修复”。正式单块数据在独立开发阶段证明参数包络满足该条件；生成时仍逐轨迹断言。物理条件失败可以在**封存之前**按预先规定的 attempt 子种子重新生成，并保存拒绝日志。不得根据 CSI NMSE、BER、深衰落或估计器失败做拒绝采样。

真正需要保留块间干扰时，应建立新的多块观测数据版本，不能将其隐藏在本版本的白噪声中。

### 4.4 真值矩阵

冻结同一条轨迹和接收窗，对单位输入子载波逐列传播得到 $\mathbf H_{true,b}$。理想单块条件下也可用等价式：

$$
[\mathbf H_{true,b}]_{km}=\frac1N\sum_{n=0}^{N-1}\sum_{p=1}^{P_h}
 g_p e^{-j2\pi(f_c+f_m)\tau_p(t_{b,n})}
 e^{j2\pi(f_m-f_k)n/F_s}.
$$

该式的参考时间与接收窗必须与直接波形传播一致。真值矩阵只用于标签、质量诊断和可选 oracle 对照，不进入四种算法的正常前向计算。

## 5. 噪声、名义 SNR 与接收噪声估计

发射路径功率归一化后，定义固定参考功率

$$
P_{ref}=|\mathcal K|/N,\qquad
\sigma_n^2=P_{ref}10^{-s/10},\quad s\in\mathrm{SNR}_{list}.
$$

生成标准复白噪声 $w[n]=(\xi_n+j\zeta_n)/\sqrt2$，其中实、虚部基础正态序列相互独立；然后 $n_s[n]=\sqrt{\sigma_n^2(s)}w[n]$。同一轨迹的所有 SNR 使用同一个标准噪声 realization 的缩放版本，或采用独立噪声版本，但该选择必须在封存前固定。主版本使用前者，四种算法始终读到完全相同的具体噪声。

数据包内信号块和训练块使用同一噪声功率；不同块不重新做 measured-power 归一化。保存实际无噪声接收功率和观测 SNR，仅作为真值诊断。若以后改变横坐标定义，优先从已有诊断重新标注，不能无理由重新均衡。

接收端从专门保留且无信号的区间估计：

$$
\widehat\sigma_n^2=\max\left(\frac1{L_n}\sum_{n=1}^{L_n}|r_{quiet}[n]|^2,10^{-12}\right),
\qquad \widehat{\mathbf R}_n=\widehat\sigma_n^2\mathbf I_N.
$$

这是主版本提供给所有算法的噪声信息。真实 $\sigma_n^2$ 不传给算法；名义 SNR 只用于实验分组，不作为 DU 控制器特征。

## 6. 实际 CSI 估计器：有限路径拟合

### 6.1 估计器能看到什么

```python
estimate_channel(
    received_training_blocks,   # 两个含噪接收训练块
    known_training_symbols,     # 接收端已知
    noise_variance_estimate,     # 从 quiet 区间得到
    fixed_receiver_config,
    target_block_times,
) -> ReceiverChannelEstimate
```

函数签名禁止出现 `H_true`、真实路径、数据标签、目标 NMSE 或真实噪声方差。为验证隔离性，单元测试用不可访问的 truth 对象运行该函数。

### 6.2 估计器模型与自然失配

真实信道使用正弦变化尺度；估计器使用有限条**常尺度路径**：

$$
 \widehat\tau_p(t)=\tau_{p,r}-a_p(t-t_r),\qquad
 \widehat H_b(\boldsymbol\theta)=\sum_{p=1}^{\widehat P}g_p\,\mathcal H_b(\tau_{p,r},a_p).
$$

$t_r$ 固定为两个训练块有效接收时刻总体区间的中点。$\mathcal H_b$ 采用第 4.4 节相同的完整矩阵公式，但代入常尺度候选路径。

误差自然来自：接收噪声、有限训练长度、离网格参数、有限估计路径数、真实尺度随时间变化、非线性拟合偏差，以及训练到数据的时间间隔。训练结束以后不使用未知数据标签继续估计 CSI。

主版本只从两个完整训练块估计并预测四个数据块；数据块导频用于已知符号消除和可选信道细化。后续若加入数据导频跟踪，必须发布新的 receiver/data 版本，而不能在某个均衡器测试时临时改变共同前端。


这些是接收算法的冻结参数，不是实际信道真值。

所有候选路径还必须满足接收协议的单块可采样约束：对两个训练块与四个目标数据块的每个有效接收采样时刻，均有

$$-T_{CP}\le n/F_s-\widehat\tau_p(t_b+n/F_s)<T_u.$$

先从固定网格中排除不满足条件的候选；这只使用候选参数、已知块时间和 CP，不读取真实路径。连续细化的每个候选步在区间投影后还需检查这一约束，违反则继续回溯，不能把越过 CP/块边界的候选按无条件循环延拓计算。数值边界保留固定的半个采样间隔安全裕度；局部中心差分也必须在该裕度内。

### 6.4 网格选择与初始增益

将两个训练块观测堆叠为 $\mathbf z\in\mathbb C^{M_o}$，$M_o=2N$。对候选 $(\tau_q,a_q)$ 构造

$$
\boldsymbol\phi_q=
\begin{bmatrix}\mathcal H_{tr,1}(\tau_q,a_q)\mathbf p_{tr,1}\\
\mathcal H_{tr,2}(\tau_q,a_q)\mathbf p_{tr,2}\end{bmatrix}.
$$

对白噪声进行标量白化。相关搜索采用归一化字典方向，但支持集岭拟合保留原始白化列的物理增益尺度。OMP 每一步选择

$$
q^*=\arg\max_{q\notin\mathcal S}
\frac{|\boldsymbol\phi_q^H\mathbf r|^2}{\|\boldsymbol\phi_q\|_2^2}.
$$

并列时选最小固定网格编号。重新求解所选支持上的岭最小二乘，而不是只更新一个增益：

$$
\widehat{\mathbf g}=\left(\Phi_\mathcal S^H\Phi_\mathcal S+
\lambda_{OMP}\mathbf I\right)^{-1}\Phi_\mathcal S^H\mathbf z.
$$

上式的 $\Phi,\mathbf z$ 均表示已按 $\widehat\sigma_n$ 白化后的量。达到最大路径数，或在至少选择一条路径后满足 $\|\mathbf r\|^2\le1.1M_o$，停止 OMP。所有停止原因均保存。

### 6.5 连续参数细化

定义实参数

$$
\mathbf u=(\{\Re g_p\},\{\Im g_p\},\{\tau_{p,r}/\tau_u\},\{a_p/a_u\})^T.
$$

设复预测为 $\mathbf f(\mathbf u)$，白化实观测与预测为

$$
\mathbf z_w=\frac{\sqrt2}{\widehat\sigma_n}[\Re\mathbf z;\Im\mathbf z],\quad
\mathbf f_w(\mathbf u)=\frac{\sqrt2}{\widehat\sigma_n}[\Re\mathbf f;\Im\mathbf f].
$$

**此节 $\mathbf z$ 是未白化的原复观测，不能对白化后的 OMP 观测再次除以噪声标准差。**

最小化

$$
J_{CE}(\mathbf u)=\frac12\|\mathbf z_w-\mathbf f_w(\mathbf u)\|^2+
\frac{\lambda_{CE}}2\|\mathbf u-\mathbf u_0\|^2,
$$

其中 $\mathbf u_0$ 是 OMP 初值。令 $\mathbf J_w=\partial\mathbf f_w/\partial\mathbf u$，则求解

$$
(\mathbf J_w^T\mathbf J_w+(\lambda_{CE}+\mu)\mathbf I)\Delta\mathbf u
=\mathbf J_w^T(\mathbf z_w-\mathbf f_w)-\lambda_{CE}(\mathbf u-\mathbf u_0).
$$

按配置的 $2^{-k}$ 步长依次尝试，在延迟、尺度边界投影后，接受第一个使 $J_{CE}$ 严格下降的候选；没有下降则停止并记录。增益没有人为幅度截断。不得用真实参数初始化或决定步长。

接收器最终按估计延迟排序路径，其他状态同步重排；保留初始与最终目标值、所选路径数、残差和状态码。数值失败时输出 OMP 的有限结果并标记 `ce_status=fallback_omp`，不丢弃样本。没有任何有限解则数据构建失败，修复实现并生成新候选版本，不能放入损坏的正式样本。

### 6.6 从同一估计预测目标块

$$
\widehat{\mathbf H}_b=\sum_{p=1}^{\widehat P}\widehat g_p
\mathcal H_b(\widehat\tau_{p,r},\widehat a_p).
$$

每个数据块均使用它自己的绝对接收时刻。不能将训练块的矩阵原样复制到未来块；也不能把真实数据块路径偷偷代入。

## 7. DU 所需的误差基与 $\mathbf C_0$

### 7.1 来源限制

基矩阵和系数先验由上述**接收估计及其观测统计**生成，封存到统一接口。三种 baseline 可以不使用这些字段，但接口并不只向 DU 提供额外真值。所有方法都可访问同一接收侧资产。

### 7.2 局部基矩阵

每条估计路径构造三类基，总计 $Q=3\widehat P\le24$：

$$
B_{g,p}^{raw}=\mathcal H_b(\widehat\tau_{p,r},\widehat a_p),
$$

$$
B_{\tau,p}^{raw}=\left.\frac{\partial H_b}{\partial(\tau_{p,r}/\tau_u)}\right|_{\widehat{\mathbf u}},\qquad
B_{a,p}^{raw}=\left.\frac{\partial H_b}{\partial(a_p/a_u)}\right|_{\widehat{\mathbf u}}.
$$

延迟和尺度导数包含对应路径的估计复增益；$B_g$ 对应复增益误差。可用解析导数或配置固定的中心差分实现，二者必须在开发单测中一致。中心差分只计算局部矩阵导数，不重新运行 CSI 估计器。

若 $\delta\mathbf u$ 是实参数误差，定义固定复矩阵 $\mathbf T_c$，使

$$
\delta\mathbf c^{raw}=\mathbf T_c\delta\mathbf u
=(\{\delta\Re g_p+j\delta\Im g_p\},\{\delta(\tau_{p,r}/\tau_u)\},\{\delta(a_p/a_u)\})^T.
$$

### 7.3 接收侧近似参数协方差

在最终估计处取

$$
\widehat s_{CE}=\max\left(1,
\frac{\|\mathbf z_w-\mathbf f_w(\widehat{\mathbf u})\|^2}
{\max(2M_o-4\widehat P,1)}\right),
$$

$$
\Sigma_u=\widehat s_{CE}
(\mathbf J_w^T\mathbf J_w+\lambda_{CE}\mathbf I)^{-1}.
$$

这是带正则化的局部高斯近似，不是已知真实 CSI 误差协方差。LM 数值步长中的 $\mu$ 不自动加入该统计模型。

构造

$$
C_0^{raw}=\mathbf T_c\Sigma_u\mathbf T_c^H.
$$

归一化每个基：

$$
b_q=\|B_q^{raw}[:,\mathcal K]\|_F,\quad B_q=B_q^{raw}/b_q,
$$

$$
\mathbf C_0=\operatorname{Herm}(\mathbf D_bC_0^{raw}\mathbf D_b^H)+\epsilon_C\mathbf I_Q.
$$

删除活动列 Frobenius 范数小于 `1e-12` 的基时必须同步删除相应行列并保存 mask。固定批处理采用按 $Q$ 分桶，或零基填充配合有效 mask，不能让不同样本共享错误的协方差。

延迟、尺度系数本来是实误差；DU 中使用只保留 $\mathbb E[\delta c\delta c^H]$ 的适当复高斯代理，不利用伪协方差。这是明确的近似，不能称为完整真实后验。未知路径和时变模型阶数不足可能落在基底外；质量报告需要测量这一点，不能用真值偷偷补足主算法的 $C_0$。

## 8. 统一均衡器输入与标签隔离

### 8.1 接收输入 `EqualizerInputV1`

该类的序列化契约 ID 为 `receiver_input_v1`；统一输出类 `EqualizerOutputV1` 的契约 ID 为 `equalizer_output_v1`。类名、schema ID 和算法版本是不同字段，不可混作同一个版本键。

| 字段 | 形状/类型 | 语义 |
|---|---|---|
| `sample_id` | UTF-8 | 全局稳定样本编号 |
| `input_sha256` | string | 公共接收字段的逻辑内容哈希，不含标签或算法名 |
| `optional_features_sha256` | string | $B,C_0$ 的不可变表示及解释器版本哈希 |
| `y` | complex128 `[N]` | 完整 FFT 观测，含所有接收行 |
| `H_hat` | complex128 `[N,N]` | 完整 ICI 接收估计；可由封存表示确定性展开 |
| `R_n_hat` | scalar 或 `[N,N]` | 主版本为估计噪声方差乘单位阵 |
| `data_idx` | int64 `[D]` | 输出数据符号顺序 |
| `pilot_idx` | int64 `[P]` | 已知导频发射位置 |
| `pilot_symbols` | complex128 `[P]` | 本块已知导频 |
| `data_group` | int64 `[D]` | 按真实有符号频率划分为 8 组 |
| `B` | complex128 `[Q,N,N]` / 确定性算子 | 接收侧残差基 |
| `C0` | complex128 `[Q,Q]` | 与基归一化一致的先验 |
| `receiver_state` | 结构体 | 估计路径、参考时刻、估计状态，不含真值 |

公共哈希覆盖 $y,\widehat H,\widehat R_n$、导频/数据索引、导频值、分组和实际信号约定，四个算法共享同一值。算法实际输入签名再按其是否使用附加字段组合 `optional_features_sha256`；比较时检验公共输入哈希，不能要求不同算法的部署相关输入键相等。

算法前向不得使用用于统计分组的 `snr_db` 或 `regime`，除非未来版本明确变更信息条件。主版本传给模型的 dataclass 不含这两个字段。

### 8.2 标签及评估索引

`LabelV1` 单独保存 `tx_bits[D,2]`、`tx_class[D]`、`tx_symbols[D]`。启用 FEC 时额外保存信息比特、编码映射、交织信息以及 codeword 对应块。

`SampleIndexV1` 保存 `trajectory_id`、`frame_id`、`block_id`、`snr_id`、`snr_db`、`regime`、`split`、各子种子、接收输入位置、标签位置和真值位置。评估器用索引统计；算法不能通过索引对象访问标签。

`TruthV1` 保存真实路径、无噪声接收波形/算子、实际噪声、$H_{true}$ 的完整表示，以及 ICI、NMSE 等诊断。只允许质量检查和评估指标模块访问。

### 8.3 稠密矩阵的存储量与精确紧凑表示

1024×1024 的 complex128 矩阵约为 16 MiB；为每个样本重复保存 $H$ 和 24 个基会迅速耗尽磁盘。主版本使用 `receiver_factorized_exact_v1` 保存：估计路径参数、参考时刻、目标块时刻、生成算子版本、协方差、基归一化系数和固定索引。

`DatasetLoader` 根据这些**已保存的接收估计**确定性展开出 `H_hat/B`，不重新估计 CSI、不抽样、不读取真值、不访问标签。它不是算法改进的一部分。必须有“紧凑表示展开 = 封存时稠密参考矩阵”的哈希/容差检查。

同一份输入展开代码属于数据解释器依赖，四个算法共用。它的变化可能改变实际输入时，必须变更接口/数据表示版本并重新验收；仅换存储压缩而解码字节完全一致不应触发均衡重测。可使用只读本地 LRU 或内容寻址的矩阵展开缓存，缓存键是接收表示的内容哈希，不是算法名。

## 9. 随机性、分组划分与可复现生成

### 9.1 不依赖执行顺序的种子

先生成不可变轨迹清单，再启动多进程。每个随机流用语义键派生：

```python
seed_key = canonical_json({
    "root_seed": 20260926,
    "dataset_version": "vampnet_natural_v1",
    "split": split,
    "regime": regime,
    "trajectory_id": trajectory_id,
    "purpose": purpose,   # channel / bits / pilots / training / noise / retry
    "attempt": attempt,
})
seed128 = int.from_bytes(sha256(seed_key).digest()[:16], "little")
rng = numpy.random.Generator(numpy.random.PCG64(seed128))
```

本项目派生方法由以上公式定义，不能使用进程 ID、Python 内置 `hash()`、当前时间或任务完成顺序。NumPy 的独立随机流机制可作为实现参考，但算法、版本和派生约定都要锁定。[D3]

当跨 SNR 共用标准噪声时，noise 子键不包含 SNR；缩放系数由 `snr_db` 决定。接收训练观测随缩放变化，因此每个 SNR 必须重新运行一次接收估计器并持久化其输出；这发生在**数据生成阶段一次**，不是每次测试算法都重做。

### 9.2 样本编号

```text
trajectory_id = strong-test-tr000119
sample_id     = vampnet_natural_v1__strong-test-tr000119__b03__snr_p020
```

`snr_id` 用规范十进制字符串或固定整数单位表示，不依赖浮点字符串的默认格式。每个 `sample_id` 全局唯一，同一轨迹所有版本必须属于同一个 split。

### 9.3 环境锁定

保存 Python、NumPy、线性代数库、PyTorch、CUDA/驱动、操作系统、线程数、容器镜像摘要和依赖锁文件。正式生成采用固定 dtype、固定 FFT 归一化和无随机近似的求解器。神经网络训练的确定性还需控制 CUDA 算法选择；即使随机种子相同，跨版本或跨平台也不保证逐位一致。[D4]

## 10. 质量验收：先证明正确，再证明场景成立

### 10.1 硬性数学测试

| 测试 | 输入设置 | 验收标准 |
|---|---|---|
| QPSK 往返 | 四种类别各一次 | 比特、类别、符号精确一致 |
| FFT 往返 | 固定随机向量 | float64 相对误差 ≤ 1e-12 |
| 静态单位信道 | 单位路径、无噪声 | $H\approx I$，误码为零 |
| 静态分数时延多径 | 时延恒定、CP 合格 | 非对角能量比例 ≤ 1e-10；对角与解析频响一致 |
| 单音宽带多普勒 | 常尺度单路径 | 三个不同频率均符合 $(f_c+f_m)a$ |
| 时延导数 | 正弦尺度 | 数值差分的 $-\tau'$ 与 $a$ 一致 |
| 波形/矩阵一致 | 固定完整轨迹 | $\|y_{clean}-H_{true}s\|/\|y_{clean}\|≤10^{-10}$ |
| CP 负例 | 故意缩短 CP | 必须检测出至少一个跨块读取 |
| 源块隔离 | 改变相邻块、当前块不变 | 合法单块条件下当前观测不变 |
| 接收端防泄漏 | truth 对象禁止访问 | CSI 估计、输入展开正常完成 |
| 同种子同环境 | 串行与并行生成 | 逻辑数组哈希一致 |

阈值对应理想连续波形参考实现；若改成有限阶插值，必须新增插值收敛测试和版本，不得直接放宽所有错误容差。

### 10.2 噪声与 AWGN 链路

检查 $E|n|^2=\sigma_n^2$、实虚部各为 $\sigma_n^2/2$、近零伪协方差、时域样本相关和 FFT 后功率。偏差用样本量对应的置信区间衡量，不要求有限样本恰好相等。

独立 AWGN 单元测试按每个数据符号能量定义 $E_s/N_0$，验证 Gray QPSK

$$P_b=Q(\sqrt{2E_b/N_0}),\quad E_s=2E_b.$$

这个测试不含 CP/导频开销换算；不能直接用本数据的名义 SNR 替代该式里的 $E_b/N_0$。

### 10.3 实际估计器验收

在单路径或支撑已知的模型匹配开发单测中，关闭正则并使用充分收敛的参考求解，核对接收训练残差接近数值误差。正式有限步、带正则的非线性估计器不要求在所有多径样本上达到机器精度；记录最终目标、驻点残差与停止原因。在有噪声、真实时变模型上，输出必须有限，并记录估计路径数、失败率和预测误差分布。

增加训练功率/训练块、缩短估计到数据的间隔等检查只在开发集执行；观察总体趋势，不要求每个样本的 NMSE 都单调。正式集里 $H_{true}$ 只在质量程序中用于计算结果，不能反馈给估计器。

### 10.4 ICI、时变程度与 CSI 误差

逐样本保存以下诊断：

$$
\Gamma_{ICI}=\frac{\sum_{m\in\mathcal K}\sum_{k\ne m}|H_{km}|^2}
{\sum_{m\in\mathcal K}|H_{mm}|^2},
$$

$$
\eta_{tail}(w)=\frac{\sum_{m\in\mathcal K}\sum_{d_N(k,m)>w}|H_{km}|^2}
{\sum_{m\in\mathcal K}\sum_k|H_{km}|^2},\quad
w_{99}=\min\{w:\eta_{tail}(w)\le0.01\},
$$

$$
\mathrm{NMSE}_{H,in}=\frac{\|(\widehat H-H_{true})[:,\mathcal K]\|_F^2}
{\|H_{true}[:,\mathcal K]\|_F^2}.
$$

其中 $d_N(k,m)=\min(|k-m|,N-|k-m|)$。另外按路径功率计算载频处瞬时 $\nu_p(t)=f_ca_p(t)$ 的均值、路径间标准差 $\sigma_\nu(t)$，记录 $\sigma_\nu T_u$ 的时间统计及块内变化。公共残余频偏与多普勒扩展分别保存。

报告按 regime、SNR、数据块年龄分组的分位数，而不是仅给总体均值。regime 是生成条件标签，不等同于已测得的 ICI 带宽。宽带时间尺度效应和“干扰跨越很多子载波”需要分别验证。[D1]

可在独立诊断中投影真实 CSI 误差到接收基底，测量基底外能量占比。此投影结果仅用于判断模型覆盖率，禁止写回正式输入 `C0` 或 `B`。

`generation_manifest.json` 至少包括：

```json
{
  "schema_version": "dataset_schema_v1",
  "dataset_version": "vampnet_natural_v1",
  "test_set_version": "test_v1",
  "root_seed": 20260926,
  "generator_code_digest": "<由相关源码计算>",
  "receiver_code_digest": "<由估计器相关源码计算>",
  "matrix_materializer_digest": "<由输入展开相关源码计算>",
  "generation_config_digest": "<规范配置SHA256>",
  "channel_config_digest": "<信道配置SHA256>",
  "ofdm_config_digest": "<OFDM配置SHA256>",
  "modulation": "QPSK_unit_energy_00_01_10_11",
  "snr_list": [0, 5, 10, 15, 20, 25, 30],
  "split_manifest_digest": "<分组划分SHA256>",
  "test_manifest_digest": "<测试清单SHA256>",
  "asset_digests": {},
  "shard_digests": {},
  "environment_lock_digest": "<锁文件SHA256>",
  "status": "SEALED"
}
```

上述尖括号是构建程序必须填写的字段，不是可使用的哈希值。规范 JSON 禁止 NaN/Infinity，键排序、UTF-8、无无关空白；数组哈希包含字段名、dtype、shape、端序及 C-order 内容。

`test_manifest.json` 包含**有序完整样本清单**及每条的 `input_sha256`、`label_sha256`、`truth_sha256`、轨迹与 SNR 标识。`test_content_digest` 是这些有序条目的规范哈希。仅有同名目录、相同条数或相同 seed 不足以确认同一测试集。

封存流程：写临时目录 → 验证全部 shard → 验证 split 无交集 → 生成内容哈希 → 写完整性报告 → 原子发布 → 写 `SEALED.json` → 只读权限。中断的候选数据不得被正式 loader 接受。

## 12. 增量实验约束及命令契约

以下命令是将来必须实现的 CLI 契约，本交付不包含对应 Python 程序。

```bash
# 独立开发集和质量检查；不能使用正式 test 做接收器调参
python -m vampnet.cli.data_generate --config configs/data/debug_natural.yaml
python -m vampnet.cli.data_validate --dataset data/debug_natural

# 前端和物理模型冻结后，只生成一次正式数据
python -m vampnet.cli.data_generate --config configs/data/vampnet_natural_v1.yaml
python -m vampnet.cli.data_validate --dataset data/vampnet_natural_v1
python -m vampnet.cli.data_seal --dataset data/vampnet_natural_v1

# 以后的算法实验：只读 sealed 数据，不再 generate
python -m vampnet.cli.train --algorithm udnet --config configs/training/udnet_v1.yaml
python -m vampnet.cli.train --algorithm vamp_du --config configs/training/vamp_du_v1.yaml
```

数据生成阶段也支持 shard 级续作：相同生成语义与相同内容已完成则复用，缺失则补齐，损坏则只修复损坏 shard。封存后不允许“补写一个 SNR”到原版本；扩展产生 `test_v2` 并显式引用 `test_v1` 的不变分区。旧样本预测是否可跨版本复用，由文档 04 的逐样本内容匹配决定。

改变绘图、对比表、Markdown 或某个算法的代码，不改变本数据。新增算法不重新生成测试集。若接收估计器改变，则是共同输入改变，需要新的数据版本；旧结果保留用于旧实验，而不是覆盖删除。
