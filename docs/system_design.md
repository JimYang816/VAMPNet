# 仿真数据生成器设计

## 波形与物理回放

`configs/simulation.json` 描述当前生成器；已生成数据以 manifest 中保存的配置为准。
数据集标识为 `ncs1_qpsk_ofdm_6khz_lfm_pair`。

512 点 FFT，有符号索引 −256…255，复基带采样率 6000 Hz，频率间隔 11.71875 Hz。
两端各 32 个保护载波，448 个活动载波为 −224…223，直流参与数据承载。
导频 −221:7:220 共 64 个，其余 384 个活动载波承载数据。
通带采样率为 96000 Hz，载频为 14000 Hz，接收噪声带宽为 6000 Hz。

CP 为 192 个基带样点（32 ms），每个 OFDM 块为 704 点。
帧段偏移为从帧首开始的零基基带样点数：

| 帧段 | 样点数 | 起始偏移 |
|---|---:|---:|
| 128 ms 上扫频 LFM，扫频 −2625…2625 Hz | 768 | 0 |
| 32 ms 静默 | 192 | 768 |
| 训练槽 1、数据槽 2/3/4/5、训练槽 6、数据槽 7/8/9/10 | 7040 | 960 |
| 32 ms 静默 | 192 | 8000 |
| 与首段相同的 128 ms 上扫频 LFM | 768 | 8192 |

整帧为 8960 点，约 1.493333 秒；每帧生成 8×384 个 QPSK 符号。
首尾 LFM 起点间距为 8192 点，约 1.365333 秒。

官方 `replayfilter.m` 使用完整原始时延响应及其时间变化，
`replay_ncs1_record` 按官方名义 V0 规则恢复时间尺度。
原始响应时延覆盖和回放 padding 按 `delay_bins/fs_tau` 计算，为 31.875 ms；
193 个模型抽头覆盖 0…32 ms，CP 同时覆盖该时延。

## 接收前端与信道估计

对每个 SNR 独立加入通带噪声。在未补偿的接收复基带中，
用相同上扫频模板搜索首尾相关峰，搜索范围覆盖配置的 ±0.5% 尺度、最大时延和相关峰偏移。
复相关先做带限插值，再确定亚样点峰位置。

名义峰间距为 Δ，观测间距为 Δr，定义 `alpha=Δ/Δr-1`。
接收位置使用 `known_start+n/(1+alpha)`，整帧补偿一次。
LFM 只估计尺度，不修改仿真已知起点；OFDM 按固定 payload_offset 和 CP 截取。

两个已知训练槽各拟合 193 个抽头的复值与符号内线性变化率，使用 `ce_ridge=0.001`。
前四数据槽使用两次训练估计进行相位感知 Hermite 插值；
后四数据槽分别重新以第二训练槽中心值及局部变化率建立先验，不跨多个槽外推。
每个数据槽再用本槽 64 个导频进行岭正则增量校正，`pilot_ridge=0.01`。
导频不能独立确定全部 193 个抽头，校正保留先验在导频不可观测子空间中的分量。

完整时变 FIR 经 FFT 变换形成频域矩阵，再提取数据行列并扣除估计导频贡献，
输出 384 维观测和 384×384 估计矩阵，不截断远邻 ICI。
接收前端和信道估计器不读取真实信道或未知发送标签。
首尾 LFM 和第二训练槽带来整帧接收延迟；输出 CSI 包含噪声和模型失配。

## 数据写入

记录级划分、随机种子、六档配对 SNR 均由现有生成流程保持。
`noise_var` 为冻结接收前端后的模拟器测量值，不包含 CSI 误差。
生成器另保存模型残差和估计 ICI 能量等元数据，不按这些量剔除样本。

每个记录/SNR 写一个 HDF5 分片，先写 `.partial` 再移动为最终文件。
manifest 保存配置、官方 ZIP 哈希、代码签名、来源记录、分片列表及完成状态。
生成器只续写兼容配置和签名的数据，不覆盖既有分片。
输出轴约定及字段见 [数据格式](dataset_schema.md)。
